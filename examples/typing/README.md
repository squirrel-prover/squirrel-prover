Exemples in this directory concern proofs using the tactic `typing`.
This tactics is presented in:  
*Secrecy by typing in the computational model.* Stéphanie Delaune, Clément Hérouard, Joseph Lallemand.  
Published in the proceedings of CSF 2025.  
Exemples using signature schemes are yet to be published.

Files in the directory `ok` are exemples of well-typed protocols and proofs possible with `typing`, while `ko` gives exemples of limitations of the type system. The directory `without-typing` contains an example without typing to exemplify the length of a proof without this method.
