This repository contains all the example from the paper "Are ideal
functionalities really ideal?" - M. Arapinis, V. Cortier, H. de
Groote, C. Jacomme, S. Kremer.

Each green tick from the Table 1 of the paper corresponds to one file
in this folder, which contains a Squirrel model and the proof. For
each model, some comments indicate which part of the file models the
protocol, which parts are proof lemmas, and the final security theorem
is at the end of the file.
